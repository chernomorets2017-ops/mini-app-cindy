# CCD RACE — что изменено и что нужно доделать вручную

## Файлы
- `index.html` — клиент (Mini App). Дизайн переработан в неоновую гоночную тему,
  добавлены звук, ИИ-боты с уровнями сложности, реальный вызов backend для
  подписки/платежей, WebSocket-клиент для комнат и матчмейкинга на 10 игроков.
- `server.js` — backend (Node/Express/ws/node-telegram-bot-api), который
  реально выполняет то, что клиент выполнять не может:
  - проверка подписки через `getChatMember`
  - создание и подтверждение платежа через `sendInvoice`/`createInvoiceLink`,
    `pre_checkout_query`, `successful_payment`
  - WebSocket-комнаты (с другом и публичный матчмейкинг до 10 игроков)

## Что нужно подставить перед запуском
1. В `index.html`:
   - `API_BASE` — адрес вашего backend (https)
   - `WS_URL` — адрес WebSocket (wss)
   - Файлы `sounds/*.mp3` — сейчас это плейсхолдер-пути, звуковых файлов в
     репозитории нет (авторские права на музыку/SFX — добавьте свои).
2. В `server.js` / переменных окружения:
   - `BOT_TOKEN` — токен вашего Telegram-бота
   - `CHANNEL_ID` — `@mods_ccd` (бот должен быть администратором канала,
     иначе `getChatMember` вернет ошибку)
   - `PROVIDER_TOKEN` — провайдер-токен ЮKassa. **Никогда не хранится в
     клиенте** — только на сервере через ENV.
3. Замените in-memory `balances`/`pendingInvoices`/`rooms` на настоящую БД
   (Postgres/Redis) перед продакшеном — сейчас это упрощенная реализация,
   которая обнуляется при перезапуске сервера и не переживает несколько
   инстансов backend.
4. В боте у @BotFather включите платежи и привяжите провайдера ЮKassa,
   иначе `createInvoiceLink` будет возвращать ошибку.
5. Приглашение друга использует `https://t.me/mods_ccd_bot/app?startapp=room_ID`
   — замените `mods_ccd_bot` на username вашего реального бота.

## Что осталось на усмотрение (за рамками кода)
- Матчмейкинг сейчас — одна общая лобби-комната до заполнения; для продакшена
  стоит сделать очередь с несколькими параллельными комнатами и таймаутом
  автозапуска, если 10 человек не набралось.
- Хиты/детект чит-инжекта скорости (клиент присылает `speed`/`distance` без
  проверки на сервере) — для честного соревновательного режима добавьте
  server-side валидацию физики (макс. ускорение за тик и т.д.).
